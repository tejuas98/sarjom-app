# SARJOM — Final Technology Stack (names only, matches slide)

Mobile App: React 19, Capacitor 8, Android WebView Runtime
Speech and Audio: Web Speech API, SpeechSynthesis TTS, Dual-Formant Web Audio Synthesizer, native-speaker studio clips
NLP and Translation: On-Device Cascade NLP Engine, cosine similarity semantic matcher, curated 4-language tribal lexicon
ASR: browser Web Speech recognition (hi-IN), 1-tap prompt chips, typed input
Script and Phonetics: Ol Chiki to Devanagari transliteration, Warang Chiti Unicode support
Offline and Edge: Service Worker, CacheStorage, localStorage (zero server at runtime)
Pedagogy and Standards: NIPUN Bharat FLN (80:20), NEP 2020 MTB-MLE
ML Research Pipeline: PyTorch Transformer, LoRA PEFT, ONNX INT8
Build and Test: Vite 8, Node.js, Puppeteer, Gradle

100% open-source, zero server at runtime, fully offline on 2 GB RAM tablets.
